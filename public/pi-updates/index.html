PixInsight Scripts

Free PixInsight scripts by Carl Baker.

Install

  1. In PixInsight, open Resources > Updates > Manage Repositories.
  2. Click Add and enter https://astro.wiibopp.com/pi-updates/
  3. Run Resources > Updates > Check for Updates, install, and restart PixInsight.

The scripts are not code-signed, so PixInsight will ask you to confirm before installing.

Scripts

  • RemoveSmallStars (Script > Utilities) — removes stars below a chosen pixel size from a stretched image while leaving larger stars untouched, with a live preview and optional starless recombination.
